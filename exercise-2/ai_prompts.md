# AI Prompts Used

## Exercise 2 – Worker Progress Report 

### Prompt 1 – Initial Form Recreation

> Create an HTML, CSS, and JavaScript project that recreates the uploaded Worker Progress Report PDF as accurately as possible. Match the original page size, layout, spacing, borders, headings, labels, text alignment, and overall appearance. The form should contain all three pages shown in the PDF.

### Prompt 2 – Interactive Checkboxes

> Add dynamic and clickable checkboxes to the Worker Progress Report form. The checkboxes should behave like the original form. In sections marked "Select one", only one checkbox should be selectable at a time. Make the pain scale from 1 to 10 interactive as well.

### Prompt 3 – PDF Layout Matching

> Compare the generated HTML form with the uploaded Worker Progress Report PDF and adjust the layout so that it closely matches the original. Fix page dimensions, section positions, borders, margins, line spacing, text alignment, and footer placement.

### Prompt 4 – Font and Typography

> Fix the fonts and typography of the HTML form so they closely resemble the uploaded PDF. Use appropriate font families and sizes for headings, body text, labels, footer text, and form fields. Make sure the text does not become oversized or wrap incorrectly.

### Prompt 5 – Fix Overlapping Text

> Inspect the generated Worker Progress Report and fix all overlapping text and labels. In particular, correct the positioning of "Medical Provider Type", "Date", "Medical Provider Name", "Name of prescribed medication", and employer contact labels. Ensure every label is aligned with its corresponding input line and does not overlap surrounding text.

### Prompt 6 – Page 1 and Page 2 Spacing

> Adjust the vertical spacing and dimensions of the sections so that text remains inside the correct boxes and no sections overlap. Preserve the original PDF structure while making wrapped text fit naturally within each section.

### Prompt 7 – Print and PDF Support

> Add a Print / Save PDF button to the HTML form. Create print-specific CSS so that the browser prints the form as three properly sized pages matching the original Worker Progress Report layout. Hide interactive controls such as the toolbar when printing.

### Prompt 8 – Reset Functionality

> Add a Reset button that clears all selected checkboxes and user-entered values and restores the form to its initial state.

### Prompt 9 – Final Visual Correction

> Use the uploaded Worker Progress Report PDF as the visual reference and perform a final visual review of the HTML, CSS, and JavaScript implementation. Correct any remaining differences in fonts, spacing, alignment, borders, checkbox placement, line placement, and page breaks without removing the interactive functionality.
