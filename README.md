# DIONA - HTML, CSS & JavaScript Assignment

This repository contains the two exercises completed as part of the assignment using HTML, CSS, and JavaScript.

## Repository Structure

- `exercise-1/` – Medical and Travel Expense Request implementation
- `exercise-2/` – Worker Progress Report implementation

---

## Exercise 1

### Description

Medical and Travel Expense Request is a front-end implementation created using HTML, CSS, and JavaScript based on the requirements provided in the assignment.

### Technologies Used

- HTML5
- CSS3
- JavaScript

### Files

- `index.html` – HTML structure and content
- `styles.css` – Styling and layout
- `script.js` – JavaScript functionality
- `ai_prompts.md` – AI prompts used during development

---

## Exercise 2 - Worker Progress Report

### Description

Exercise 2 is a web-based recreation of the provided Worker Progress Report PDF using HTML, CSS, and JavaScript.

The project focuses on closely matching the original document's layout, typography, spacing, borders, sections, and overall appearance while providing interactive form functionality.

### Features

- Three-page Worker Progress Report layout
- Interactive checkboxes
- Dynamic "Select one" checkbox functionality
- Interactive pain scale from 1 to 10
- Form input fields
- Reset functionality
- Print / Save as PDF functionality
- Print-specific styling
- Structured layout matching the reference PDF

### Technologies Used

- HTML5
- CSS3
- JavaScript

### Files

- `index.html` – Worker Progress Report form
- `styles.css` – Styling, layout, typography, and print styles
- `script.js` – Interactive functionality
- `ai_prompts.md` – AI prompts used during development

## How to Run

### Exercise 1

1. Open the `exercise-1` folder.
2. Open `index.html` in a web browser.
3. For the best experience, use VS Code with Live Server.

### Exercise 2

1. Open the `exercise-2` folder.
2. Open `index.html` in a web browser.
3. For the best experience, use VS Code with Live Server.
4. Use the interactive checkboxes and form controls.
5. Use the Print / Save PDF option to generate the final document.
